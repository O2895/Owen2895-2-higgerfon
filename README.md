# ElderPals

> **Tagline:** Walk, Collect, Connect, Contribute — Age Joyfully.

A wearable accessory (smart bracelet/watch) paired with a mobile app that turns daily walking, exploration, and social connection into a joyful, low-pressure Pokémon-Go + Tamagotchi + gacha-style experience tailored for elderly users.

## Core Concept

- **Physical activity** — walk to earn Vital Points
- **Collection** — discover animals by exploring real-world locations (Pokémon-Go style)
- **Social connection** — meet nearby players at Elder Landmarks, trade animals
- **Purpose** — micro-jobs at partnered venues, feel useful to society

## Target Users

Elderly (60+) who often feel isolated or useless. Focus on ease-of-use: large fonts, voice commands, simple taps, big buttons.

## Core Game Loop

1. **Daily Walking & Exploration** — walk in public places to earn Vital Points
2. **Collection & Gacha** — roll for animals, buy eggs from home shop (30-min restock)
3. **Social & Community** — visit landmarks, meet players, trade animals
4. **Real-World Impact** — redeem points for perks, take micro-jobs at partners

## Tech Stack (Hackathon Feasible)

- **Frontend:** Flutter or React Native (large UI components)
- **Backend:** Firebase or Supabase (quick auth, database, real-time)
- **Maps:** Google Maps or Mapbox + geofencing
- **AI:** Simple prompt for regional animal suggestions
- **Wearable:** Prototype with phone sensors first

## Hackathon MVP Scope (2-3 days)

- **Day 1:** Core walking + animal collection UI + mock map with landmarks
- **Day 2:** Shop system + streak + simple trading UI + AI animal demo
- **Day 3:** Social proximity demo + partnership mock screens + wearable simulation + polish + pitch deck
